# Biocrash glow language

One page, so every new asset follows it and so breaking it later is a deliberate scare.

| Colour / light | Meaning | Where it's used now |
|---|---|---|
| Warm orange (fire, hazard orange) | Yours. Safe. Human-made. | Campfires, the suit's hazard band, your dropped pack and its beam, compass markers |
| Cool teal / mint (`#5fe0d0`, `#6ff0d8`, `#7affd6`) | Alive and harmless. | Mushroom spots, sprouts, night spores, Tuko eyes, Oomi pores and trails, the station core's text |
| Pale blue-white | The AI core's own light. Reliable (but it glitches). | Wrist lamp |
| No glow at all | Unknown. Be careful. | The dark between things |
| Pure black, unlit | The figure. Never lit, never glowing. | The figure (fog-tinted silhouette) |

Rules
- Bloom only touches things brighter than white (emissives and flames). Don't make ordinary surfaces glow.
- A future threat never has glowing eyes. It gets eyeshine only when your light hits it.
- Breaking the language is a scare and should be rare: a sprout patch going dark around you, an Oomi with the wrong hue, a warm light where you didn't make one.
- Days stay pastel. The day/night contrast is part of the horror.
